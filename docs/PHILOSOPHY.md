## 「疯但好使」物理学

Deshab 的风格是自相矛盾：一边封圣一边爆粗，一边敞开门一边焊死锁。

| 疯的部分 | 为什么居然没翻车 |
|---------|----------------|
| 骂街式提交历史 | commit message 只是历史涂鸦，二进制照常 build，QEMU 不读 git log |
| Logo 叫 FUCKYOU | 渲染时只认像素，不认羞耻心 |
| 全内存封缄 UTSM | 加解密纯耗时钟，不改语义——"慢但对的" |
| DKM 4-stage 填表 | Ring0 里没别人抢地址，乱序也能落进空地 |
| FirstInit 半完成 | 跳过键全部有效，向导"未完但已退"，体验反而干净 |

疯的是姿态，稳的是时序。

## 矛盾美学宣言

1. **我们不承诺安全。** 环境假设为绝对安全（无攻击者），用户行为无限自由不受限制。UTSM 存在不是因为有人窥探，是因为我们喜欢咔哒声。
2. **我们不承诺完成。** 状态表里的 ⬜ 是坦白，不是路线装饰。没写的东西不写进"核心架构"。
3. **我们承诺可演示。** 每个里程碑必须有 QEMU 证据。莲花确实开了，这比任何架构图都硬。
4. **我们承诺边界。** 已实现（✅）、演示级（🔶）、仅设计（⬜）三层分离，状态唯一来源是 [STATUS.md](./STATUS.md)。
