# 自定义内核算法与驱动配置

## 现状

- **FUCK 文件**已存在（位于 ESP `/system/deshab64/FUCK`），当前为空
- **两个内核**：UTSM（首阶段，驱动清单加载/算法初始化）→ DSK（主内核，Logo/登录/桌面）
- **读取机制**：UTSM 和 DSK 的内嵌 FAT32 解析器目前只支持根目录 8.3 文件名查找，读 FUCK 需扩展子目录路径解析
- **UTSM 读取**：通过 Limine boot module 预加载（cmdline="fuck:config"）
- **DSK 读取**：通过 FAT32 子目录遍历（路径 "SYSTEM  /DESHAB64 /FUCK    "）
- 缺失或为空时使用硬编码默认值

## 可插桩点

- **UTSM 启动流程**：arena/dma/drr/utsm_init/dkm manifest 加载/selftest/VMM+Linux guest
- **DSK 启动流程**：firstInit 检测/dev_mode/login/desktop

## 当前算法参数（编译期 `#define`，`config.h`）

- 段表 1024
- PCKC 8 密钥
- dirty shard 1024 页
- DRR 应急池 64KB

## INI 解析器

- `CODE/UTSM/kernel/ini_parser.h` / `ini_parser.c`
- 支持分区格式解析、key/value 查询、整型和布尔值便捷获取
