## 七、环境与协作约定（坑点合集，务必读完）

### 构建环境
- Windows + **PowerShell 5.1**（不能用 `&&`/`||`/三元）。
- `make.exe` 在 `C:\mingw64\bin`，clang/ld.lld 在 LLVM bin。
- 全量构建：根目录 `build.ps1`。UTSM 编译：`CODE/UTSM/MAKEFILE`（-MMD -MP，零警告）。
- **工具 MAKEFILE 普遍缺头文件依赖**：改 `desktop_app.h` 等公共头不会触发工具重编，需手动删对应 `.o`。
- **仓库内 .ps1 一律纯 ASCII**：PS5.1 把无 BOM UTF-8 按 GBK 解码，CJK 注释第三字节（0x80-0xBF）被当 GBK lead byte 会吞掉紧跟换行符，把后续代码并进注释。编辑已有含 BOM 文件保留 BOM。

### QEMU
- `ISO/run_qemu.bat`（WHPX）。WHPX 在 PE 执行处会 VP exit 4，pe-compat/deaicup-e2e 已有 TCG 自动兜底。
- **`-snapshot` 必加**（镜像只读，防 deshab.img 锁冲突，多代理并发必备）。
- monitor TCP 端口分配：deaicup-e2e 固定 45454，测试套件 45501-45509，其他按需避让。
- **Start-Process 下 `-serial file:` 不生效**（已知坑）：用临时 cmd 批处理 + `-serial stdio` 重定向到日志文件，计时按 PID 杀。
- **monitor screendump 路径必须正斜杠**：反斜杠 `\C` 转义静默失败。
- `-d reset` 非法（本版叫 `cpu_reset`）。
- 并发时**只杀自己启动的 QEMU（记 PID），绝不全局 `Stop-Process qemu`**。

### 多智能体并发协议（若继续用多 agent）
- **构建互斥**：`build.ps1` 前检查 `.build_tmp\BUILD.lock`：存在且 30 分钟内则 `Start-Sleep 15-30s` 重试，不存在才创建（写名字+PID+时间），构建+打包完成**立即删除**。
- 地盘划分：UTSM/DKM/desktop/cmd/tools/tests 分属不同 agent，不交叉改动。
- **subagent 改动落地风险**：本轮 W6 三线 subagent 报告完成但改动未入库——**接手者用 subagent 后务必核实改动是否落盘主仓库工作区**（`git status` + Grep 代码），不能只信报告。建议关键修复由主会话直接 Edit/Write 落盘。

### kernel_api ABI
- 结构体 **ABI 冻结**：成员顺序/签名不可改，**只允许尾部追加**。本轮已追加 `register_apic_eoi`、`irq_vector_alloc/free`（dkm.h 尾部）。
