宿主会打开 1280×720 SDL 窗口，直读 `deshab.img` 的 GPT ESP 分区作为 FAT32 block 后端，鼠标/键盘由 SDL 事件注入。首次启动需先在 Windows 下 `build.bat` 生成 `ISO/deshab.img`（确保 `firstInit.txt` 已是 `1`、`USER.CONF` 已存在，从而直接进桌面）。
