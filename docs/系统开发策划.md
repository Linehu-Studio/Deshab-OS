### 2.2 关键能力清单

- **kernel_api**：log/rsdp/fb_*/boot_modules/irq_register/hhdm/dma.alloc_pages/block(read@+0xA8,write@+0x18)/net
- **dsk_boot_context**：magic `0x44534B31424F4F54`，reserved[4]=pe_service，reserved[5]=linux_compat_service
- **PE service**：load/run/unload（PE32+原生Ring0，PE32走x86emu32）
- **Linux compat service**：exec(path,argv)→IPC EXEC_REQUEST(16)→daemon fork+exec→STDOUT/STDERR/EXIT
- **IPC**：1MB共享内存@GPA 0x04000000，9+5 hypercall，VMCALL RAX=`0x5554534D48430000|op`
- **FAT32**：f32_read_root_file / f32_write_root_file

## 四、开发策划

### 4.1 策划原则

先闭环再扩展；解阻塞优先于新功能；内核主线与生态主线并行；不破坏SAS-R0/O(1)热路径；文档与代码同步。

### 4.2 里程碑总览

```text
M1 持久化闭环+桌面稳定     (2–4周)  B1→FAT32 write→FirstInit写盘→桌面bug
M2 存储升级+中断后端       (4–8周)  B2高位MMIO→NVMe→B7 APIC/IOAPIC/MSI-X→e1000中断驱动
M3 兼容层验证             (与M2并行) B3/B4→Linux guest→IPC→Arch rootfs
M4 调度器+恢复+加密       (8–16周) SAS-R0-PCQ→DRR→真实加密
M5 软件生态               (依赖M3)  Pacman→AUR→desktop集成
```

### 4.3 M1 — 持久化闭环+桌面稳定

| 任务 | 验收标准 |
|------|---------|
| AHCI WRITE DMA | dkm_block_api.write注册 |
| FAT32文件覆写/创建 | f32_write_root_file可写user.conf/firstInit.txt |
| FAT32 FAT链分配 | 新文件可创建、可追加 |
| FirstInit user.conf写盘 | 重启后login可读取 |
| FirstInit鼠标光标 | PS/2 IRQ12+包解码+24×24光标 |
| 桌面fileman崩溃修复(B5) | fileman可正常使用 |
| FirstInit按键崩溃修复(B6) | -O2下fb_text稳定 |

### 4.4 M2 — 存储升级+中断后端

| 任务 | 验收标准 |
|------|---------|
| 页表映射接口 | mmio_map/unmap通用接口 |
| 高位PCI MMIO映射(B2) | NVMe BAR0可读register |
| 替换arena为真实页分配 | 移除16MB arena上限 |
| NVMe admin queue/identify+block provider | 注册nvme0 |
| IDT扩展256 vectors+vector allocator | 动态分配中断向量 |
| APIC EOI→IOAPIC redirection→LAPIC timer | 替代PIC |
| MSI/MSI-X | NVMe/e1000使用MSI-X |
| e1000中断驱动收发 | 替代polling |
| virtio-net virtqueue RX/TX | 收发包成功 |
| DKM工程化收尾 | 统一ABI头、零warning |

### 4.5 M3 — 兼容层验证

| 任务 | 验收标准 |
|------|---------|
| Linux 6.6 LTS构建+VMX运行环境 | bzImage+initramfs生成，真机VT-x或KVM可用 |
| VMX自测→Linux guest跑到shell | initramfs busybox shell可交互 |
| utsm_exec_daemon运行 | EXEC_READY(20)发送，park生效 |
| virtio-blk/net后端验证 | guest内可读写块/DHCP/ping |
| IPC exec全链路 | `linux ls`→stdout回显 |
| Arch rootfs bootstrap | pacman可用 |

### 4.6 M4 — 调度器+恢复+加密

| 任务 | 验收标准 |
|------|---------|
| SAS-R0-PCQ: TCB+task_create, Per-CPU runqueue, O(1)位图调度, context_switch(只加载crypto指针), task_kill crypto erase | 多任务调度运行 |
| DRR: Emergency Pool, Watchdog, Recovery log, Dirty Shard+Bitmap, A/B Checkpoint双槽, 三级Rollback, 驱动recovery ops | checkpoint/rollback演示 |
| 真实加密: 原语选型PoC(HKDF+AES-CTR+Poly1305), KDF, Stream cipher(64B line), MAC(4KB page), PCKC真实key schedule | UTSM真实加密selftest通过 |

### 4.7 M5 — 软件生态

| 任务 | 验收标准 |
|------|---------|
| FILE_TRANSFER+EXEC_FORWARD hypercall | 跨内核文件传输+命令委托 |
| shell path_search_and_run扩展 | PATH命中stub→IPC委托 |
| pacman装包+AUR helper | `pacman -S <pkg>`成功 |
| desktop动态Linux命令图标 | 点击图标运行Linux应用 |

### 4.8 依赖关系

```text
B1(block write)→FAT32 write→user.conf写盘→M1闭环
B2(高位MMIO)→NVMe; B7(IRQ后端)→APIC/IOAPIC/MSI-X→e1000中断驱动+virtio-net
B3(Linux构建)+B4(VMX环境)→VMX验证→guest shell→daemon→IPC→Arch rootfs
M1→M4调度器→DRR→真实加密; Arch rootfs→M5 Pacman→AUR→desktop集成
```

### 6.2 关键约束清单

- 进入C前cli/cld；早期serial不无限等待ready位
- 未启用SSE前-mno-sse -mno-sse2 -mno-mmx -msoft-float
- DATA/BSS用PF_R|PF_W|PF_X
- DSK ibuf 1MB；g_dsk_fat32_filedata 2MB；g_fdata 1MB
- FAT32批量读≥8扇区(推荐256)；DSK linker.ld BSS分离NOBITS
- mkfat32.ps1 Name83正好11字符；Linux guest cmdline含nohlt idle=poll
- VMCS不保存guest GPR，vmexit_asm.S保存16个GPR到g_guest_regs
- 调度热路径禁止扫描capability/计算MAC/写checkpoint/重加密
- DRR recovery路径禁止依赖普通堆；PE32+用__attribute__((ms_abi)) shim
