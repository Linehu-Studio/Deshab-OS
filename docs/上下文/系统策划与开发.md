## 项目现状

### 已实现并验证

- UTSM 启动内核 + 14 个 DKM 驱动（含 ath9k WiFi stub）
- DSK 主内核 + FAT32 读写 + PIE ELF loader

- Phase 5: block write + FAT32 write

## cmd.elf PE/PEINFO 命令

### 新增功能

- `peinfo <name>`: 解析 PE 头显示 DOS/NT/File/Optional Header、节区表（X/R/W 标志）、导入表（DLL + 函数名），不执行
- `pe <name>`: 显式运行 PE 程序
- PATH 查找: 先根目录（`C:\`），再 `/bin` 目录（`C:\bin\`）

### /bin 子目录支持

```c
u32 cmd_find_subdir(u32 dir_cluster, const char *name);     // 在目录簇链中查找子目录
int cmd_read_file_in_dir(u32 dir_cluster, const char *name, u8 *buf, u64 *size);  // 从指定目录读取
u32 cmd_get_bin_cluster(void);                                // 获取 /bin 目录首簇号
int cmd_read_pe_from_bin(const char *name, u8 *buf, u64 *size);  // 从 /bin 读取 PE
```

### PE 样本部署

| 文件 | 格式 | 物理路径 | FAT32 镜像路径 |
|------|------|----------|----------------|
| hello64.exe | PE32+ (1536B) | SYSTEM/bin/ | /bin/hello64.exe |
| hello32.exe | PE32 (2048B) | SYSTEM/bin/ | /bin/hello32.exe |
| cmd.exe | PE32+ (1536B) | SYSTEM/bin/ | /bin/cmd.exe |

### gen_pe.py 扩展

- `build_pe32_plus()`: 生成 PE32+ 二进制（hello64.exe）
- `build_pe32()`: 生成 PE32 二进制（hello32.exe），x86emu32 解释器兼容的操作码
- `build_cmd_exe()`: 生成 cmd.exe PE32+ 样本
